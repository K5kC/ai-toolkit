# System Prompts

Drop-in system prompts organized by use case. Copy the prompt, paste it into ChatGPT Custom Instructions, Claude Project Instructions, or Gemini Gems.

---

## Categories

- [Coding](coding/) — code review, debugging, and more
- [Productivity](productivity/) — deep work, meeting summaries, and more
- [Writing](writing/) — copywriting, editing, and more

---

**Pro tip:** Put your most important instructions at the start **and** end of the system prompt — models pay more attention there.
