## How to Use a System Prompt

1. Pick a prompt from [system-prompts/](system-prompts/)
2. Copy the text inside the code block
3. Paste it into your AI platform:
   - **ChatGPT** → Settings → Personalization → Custom Instructions
   - **Claude** → Project → Project Instructions
   - **Gemini** → Gems
4. Start chatting — the AI is already configured
